# 종목 식별자

## 용어

- 서비스 고유 심볼(stock.symbol)은 API 사용자가 종목을 지정하는 pigeon-trade 고유 값이며 증권사 매핑과 무관함
- 서비스 고유 심볼은 종목 등록 시 임시로 토스 심볼 값을 그대로 씀 — 고유 심볼을 따로 지정하는 입력은 아직 없음
- 국제증권식별번호(ISIN, stock.isin_code)는 내부 시스템의 종목 기준 식별자임
- 증권사 심볼은 증권사 API 호출에만 쓰며 증권사 구현체의 매핑 테이블에만 둠
