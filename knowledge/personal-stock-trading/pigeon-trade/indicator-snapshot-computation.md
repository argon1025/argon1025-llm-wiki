# 지표 스냅샷 계산 방식

## 규칙

- 1h 봉과 지표 스냅샷은 DB에 저장하지 않고 요청 시 candle의 1m에서 계산함 — MVP 부하가 작아 저장 테이블·마이그레이션·집계 배치 비용이 이득보다 크고, 재현은 합성키 ID로 같은 입력을 다시 계산해 보장함

## 함정

- 지표 스냅샷 입력 해시는 윈도 1h 봉의 종료 시각·OHLCV만 직렬화함 — 1h 시가·고가·저가·종가·거래량을 바꾸지 않는 1m 수정(예: 버킷 첫 1m의 종가)은 입력 변경(409)으로 감지되지 않음
