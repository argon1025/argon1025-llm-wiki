# 지갑 구현

## 규칙

- 지갑 API 경로·Swagger 설명·응답 메시지는 '모의'·'가상'·'더미' 표현 없이 일반 지갑 표현만 씀 — API를 쓰는 에이전트가 모의 지갑임을 알아채지 못하게 함
- 지갑 도메인의 별칭 pigeon은 폴더·테이블·클래스 이름에만 두고 API 경로·Swagger 설명·응답 메시지에는 쓰지 않음 — API를 쓰는 에이전트가 모의 지갑임을 알아채지 못하게 함
- 트레이드 목록(`findTrades`)은 시작 시각(openedAt) 대신 구간 첫 주문 id 내림차순으로 정렬함 — 체결 시각(created_at)이 소수 초 없는 datetime이라 같은 초에 열린 트레이드끼리 순서가 갈리지 않고, 주문 id는 체결 순서와 같음

## 결정

- 트레이드(`findTrades`)를 trade 테이블에 저장하는 안은 버리고 조회 시 계산함 — 저장 구조가 단순한 대신 조회마다 전체 이력을 다시 계산함
