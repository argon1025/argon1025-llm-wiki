# 지표 계산과 조회 방식

## 저장 정책

- 1h 봉을 저장하지 않고 요청 시 1m에서 재집계하는 방식은 버림 — 요청마다 1m 약 2만 행을 재집계하는 비용이 시간축 확장에서 커짐

## 계산 윈도

- 지표는 봉마다 대상 봉 포함 직전 200개 봉의 고정 윈도로 계산함 — EMA·Wilder 평활은 계산 시작점에 따라 값이 달라져, 조회 범위를 시작점으로 쓰면 같은 봉도 조회마다 다른 값이 나옴

## 스냅샷 방식 기각

- 지표를 스냅샷 ID·입력 해시로 저장·검증하는 방식은 버림 — 30m·1h 봉이 저장 후 불변이라 같은 봉·같은 지표 버전이면 요청 시 계산 결과가 같고 재판정 근거는 판단 기록의 입력 JSON 복사본이 담당

## 지표 선택 방식

- 지표별 API 분리와 미선택 지표의 응답 필드 생략은 버림 — 기간 미달 null과 구분되지 않는 한계를 감수한 선택, 구분이 필요해지면 미선택 필드 생략으로 전환
