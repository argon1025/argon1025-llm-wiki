# 캔들 조회 API

## 적용 대상

- 조회 API와 봉 저장·집계를 맡는 pigeon-trade(market-data 모듈), 조회 API를 호출하는 pigeon-trade-dashboard

## 규칙

- 종목 캔들 조회 API(`GET /api/stocks/:symbol/candles`)는 증권사 호출 없이 DB만 조회함
- 요청은 before(ISO 8601, 이 시각 미만, 오프셋 없는 값은 UTC, 생략 시 최신)와 limit(1~1000, 기본 200)을 받음
- 응답은 시간 오름차순 배열임
- 미등록 심볼이면 404 `STOCK_NOT_FOUND`를 반환함
- 시세 동기화 비활성 종목(enabled=false)도 저장된 캔들은 반환함
- 추가 로드는 응답의 첫(가장 오래된) 봉 timestamp를 다음 before로 넘김 — 응답에 다음 커서 필드는 없음
- 빈 배열 또는 limit 미만 응답이면 더 과거 봉이 없음
- 1d 봉은 수집·저장하지 않아 캔들·지표 API로 조회할 수 없음 — 사용처가 없음
- 과거 캔들 백필이 없어 신규 종목은 등록 이후 1m부터만 쌓임 — 과거 봉 시뮬레이션 대신 현 시세 기반 시뮬레이션을 쓰는 결정임

## 코드값

원본: `CandleInterval` 전 3종

| 코드 | 뜻 |
|---|---|
| `1m` | 증권사에서 수집한 완료 봉, 정규장 필터 없이 저장하므로 장외 봉이 섞일 수 있음 (봉 시각은 봉 종료 시각 UTC) |
| `30m` | 시간외를 포함한 저장된 1m을 UTC 정각 기준 30분 버킷(:00·:30)으로 집계해 candle 테이블에 저장한 마감 봉 (봉 시각은 봉 종료 시각) |
| `1h` | 시간외를 포함한 저장된 1m을 UTC 정각 기준 60분 버킷(:00)으로 집계해 candle 테이블에 저장한 마감 봉 (봉 시각은 봉 종료 시각) |

## 함정

- symbol 경로 파라미터가 형식 오류여도 미등록 심볼과 같은 404 `STOCK_NOT_FOUND`로 응답함 — symbol은 DTO로 검증하지 않음
- 액면분할이 생기면 저장된 과거 봉이 분할 후 봉과 가격 기준이 어긋난 채 남음 — 캔들을 수정주가(adjusted=true)로 저장하지만 분할 후 과거 봉 재수집은 아직 정해지지 않음
- 신규 종목의 첫 30m·1h 버킷은 저장하지 않고 버림(의도된 동작) — 수집 시작 시점 중간부터 담긴 부분 봉임

## 결정

- 조회 구간은 from·to 범위 대신 before+limit 방식을 택함 — 1m 봉이 종목당 수십만 행이라 범위 조회는 긴 구간을 거부해야 하고 차트 좌측 스크롤 추가 로드에 맞음
