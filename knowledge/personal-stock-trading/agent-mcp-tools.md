# 에이전트 MCP 도구

## 적용 대상

- 메인 에이전트가 실행 루프에서 쓰는 MCP 도구

## 규칙

- MCP 도구는 연결 URL로 지갑을 고정하고 도구 인자에는 지갑 식별자(walletId)를 두지 않음 — 실행 루프가 --mcp-config로 지갑을 주입해 에이전트의 다른 지갑 접근을 막으며, 도구 인자안은 프롬프트 전달·오입력 위험으로 기각
- MCP 도구는 에이전트 동작(종목 목록·캔들·지표·지갑·주문·트레이드 조회, 주문 실행, 판단 기록·조회)만 노출하고 지갑 생성·입금·종목 등록 같은 관리 동작은 REST 전용으로 둠
- MCP 판단 기록 도구는 판단 유형을 거래 처리(TRADE)로 고정하고 판단 코드는 BUY·SELL·HOLD·WAIT만 받음 — Jev의 국면 판단(REGIME) 기록은 실행 루프가 REST로 직접 호출하며, MCP 사용자는 메인 에이전트뿐임
- MCP 엔드포인트는 REST와 같이 인증 없이 두어 URL을 아는 누구나 해당 지갑으로 주문할 수 있음
