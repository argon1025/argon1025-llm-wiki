# MVP 범위

## 포함

- 국내·미국 주식, 사용자 지정 종목 풀
- 전략별 시간축(분봉~일봉)
- Jev 감시자, 메인 에이전트, 리뷰 에이전트
- 현 시세로 에이전트를 실제처럼 계속 실행하며 진행
- 최소 대시보드(에이전트 상태, 판단 타임라인, 성과 비교)

## 제외

- 토스 실주문·조건주문, 공매도 — 토스는 시세 공급원으로만 사용
- 코인, 종목 발굴 에이전트, 뉴스·공시·재무 데이터
- 안전장치(손실 상한, 주문 빈도 제한, 비상 정지)와 장애 알림 — 실제 돈이 움직이지 않음
- 에이전트 병렬 운용 — MVP는 에이전트 1~2개
- 가설 검증·판정 기준, 베이스라인 비교, 규칙 승격
- 과거 캔들 리플레이 — 과거 봉 수집 코드 유지비보다 현 시세 기반 시뮬레이션이 저렴함

## 미정

- 종목 풀 안의 종목 배정 방식(에이전트가 선택 / 에이전트마다 고정)은 아직 정해지지 않음
