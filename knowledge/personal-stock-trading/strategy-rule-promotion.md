# 전략 문서와 규칙 승격

## 전략 문서

- 전략은 `strategies/{전략}/{버전}.md` 마크다운으로 두고 git으로 버전 관리함
- 규칙 층은 확정된 엣지로 코드가 실행하고, 재량 층은 아직 규칙화되지 않은 원칙으로 LLM이 실행함
- 규칙 층만 실행한 결과가 기계식 베이스라인 v_n, 규칙 층과 재량 층을 LLM이 실행한 결과가 탐색기 — 둘의 차이가 아직 규칙화되지 않은 엣지 크기
- 메인 에이전트에는 규칙 층을 기본적으로 주입하지 않음 — 규칙을 그대로 따르면 탐색이 없음
- 버전이 올라갈수록 재량 층 내용이 규칙 층으로 옮겨가는 것이 정상

## 승격

- 여러 사이클에 반복된 후보 규칙을 규칙 층에 넣은 v_n+1이 리플레이 홀드아웃에서 v_n을 이길 때만 승인 후보 — 학습 구간에서만 이기는 규칙은 승격하지 않음
- 승인은 사용자가 대시보드에서 diff 확인 후 수행함
- 규칙 층이 5개를 넘는데 이전률이 오르지 않으면 과최적화 신호로 봄
- 이전률이 1에 가까워지면 그 전략에서 LLM의 탐색은 끝난 것으로 봄
- Jev 층도 깨움/미깨움 로그를 이후 가격 흐름으로 증류해 전략 트리거의 규칙 층으로 승격함 — 홀드아웃에서 놓친 기회가 늘지 않고 호출 수가 줄어야 함
