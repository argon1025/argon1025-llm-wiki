# 시스템 역할 경계

## 적용 대상

- pigeon-trade, 미등록 거래 루프 에이전트 프로젝트(메인 에이전트), 미등록 외부 시스템 TypeSafe AI Jev

## 규칙

- pigeon-trade는 매매 판단을 하지 않으며, Jev로 하는 판정은 사용자 참고용 종목 국면(stock.regime) 판정뿐임
- pigeon-trade에는 거래 루프 에이전트 기능을 두지 않고, 거래 루프는 pigeon-trade MCP 도구를 쓰는 별도 프로젝트가 맡음
- Jev는 거래 루프의 메인 에이전트 깨움 판단 전용 모델이 아니며, 간단한 판단을 빠르게 내리는 용도로 거래 루프 밖에서도 씀
- 거래 루프에서는 메인 에이전트 깨움 판단을 Jev가, 포지션 결정을 메인 에이전트가 맡음
