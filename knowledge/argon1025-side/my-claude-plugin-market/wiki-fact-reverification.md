# 위키 사실 재검증 표식과 주기

## 코드 미반영 표식 부재

- 개정된 값이 코드와 어긋나도 코드 미반영 표식을 두지 않음 — 코드가 따라오면 무인 갱신의 `동일` 판정이 확인 일자(verified)를 갱신해 수명주기가 닫히므로 표식이 중복이고, 레포별 후속 작업은 사용자가 진행함
- 코드가 개정을 따라와도 무인 갱신의 `동일` 판정은 본문을 고치지 않아 관찰 출처 줄이 얹히지 않음 — 확인 일자만 갱신되고 코드가 동의한다는 표시는 문서에 남지 않음

## 코드 밖 사실의 재검증 주기

- 근거가 코드 밖에만 있는 사실은 자동 재검증 경로가 없어 180일 낡음 표시가 유일한 재확인 주기임
