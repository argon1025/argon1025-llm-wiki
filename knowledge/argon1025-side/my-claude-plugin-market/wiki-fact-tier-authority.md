# 위키 사실 등급별 교체 권한

## 교체 근거 게이트

- 위키 사실이 기존 값을 덮을 수 있는지는 충돌 여부가 아니라 근거 유무로 가름 — 사용자가 건네는 사실은 오정보·향후 바뀔 정책·개정 세 유형 중 오정보만 자기 신고가 불가능함
- 코드 대조를 교체 정지점의 트리거로 삼는 안은 기각 — 코드에 근거가 없는 정책 사실을 걸러낼 수 없음

## 확인 값 교정 불가

- 기존 값을 덮을 수 있는 출처는 확인 등급뿐이고 관찰 등급은 보강만 가능함 — 잘못 들어간 확인 값은 무인 갱신으로 교정되지 않고 실행마다 확인 필요 인박스(inbox.md)에 같은 충돌 행이 다시 쌓임
