# 디자인 스타일 가이드

## 규칙

- 스타일 가이드 섹션 배열(SECTION_GROUPS)을 내보내는 셸 모듈에는 'use client'를 붙이지 않음 — 'use client' 모듈의 export는 서버 컴포넌트 페이지(StyleguidePage)에서 클라이언트 참조로만 받아져 배열을 순회할 수 없음
- 스타일 가이드 셸의 클라이언트 동작(해시 추적·모바일 시트 닫기)은 별도 클라이언트 컴포넌트(StyleguideNav)로 분리함 — 셸 모듈에는 'use client'를 붙일 수 없음

## 함정

- 해시 없이 열거나 직접 스크롤하면 스타일 가이드 사이드바의 활성 메뉴(StyleguideNav)가 바뀌지 않는 것은 의도된 동작임 — 활성 메뉴를 스크롤 위치가 아니라 마지막으로 이동한 해시(#color 등)로만 정하는 단순화임
