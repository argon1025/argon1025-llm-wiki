# 회원 폼 입력

## 규칙

- 회원 수정 폼의 학년 입력은 학교급·학년을 바꾸지 않았으면(gradeUnchanged) 졸업 표시 학생의 현재 학년(학교급 최고 학년 초과)이 선택지 밖이어도 유효로 둠 — 선택지로 검증하면 졸업 표시 학생은 이름만 고쳐도 저장이 막힘
- 회원 등록·수정 폼은 로그인 ID(loginId) 앞뒤 공백을 지워 검증·전송함 — 로그인 폼(LoginForm)이 로그인 ID 앞뒤 공백을 지워 보내므로 앞뒤 공백이 붙은 ID로 만든 계정은 로그인할 수 없음
- 회원 등록·수정 폼은 이름(name) 앞뒤 공백을 지운 뒤 필수 여부를 판정하고 지운 값을 보냄 — edu-fit-backend가 공백만 있는 이름을 막지 않음
