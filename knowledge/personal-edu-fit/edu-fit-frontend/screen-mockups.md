# 화면 목업

## 규칙

- 화면 목업 후보는 화면마다 /mock/{화면명} 경로 아래에 모아 ?type={후보}로 골라 엶 — 목업 레이아웃(MockLayout)이 개발 서버(NODE_ENV=development) 밖에서는 404를 응답함
- 후보 선정 뒤에도 목업은 지우지 않고 별도 작업에서 일괄 삭제함
- 목업 코드를 확정 화면에 쓸 때는 복사하지 않고 공용 컴포넌트 폴더(src/shared/components)로 옮김
- 옮긴 뒤 목업 후보는 import 경로만 바꿔 일괄 삭제 전까지 계속 동작시킴
