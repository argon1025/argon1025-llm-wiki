# 수업 기록과 리포트

## 적용 대상

- 수업 기록·리포트를 제공하고 권한을 강제하는 edu-fit-backend, 시간표 수업 조회 응답을 표시하는 edu-fit-frontend

## 규칙

- 수업 기록은 수업(Lesson)에만 귀속되며 수업 1건에 여러 개 둘 수 있음
- 시간표 수업 조회는 수업 기록 중 최신 1건을 함께 실음
- 학생에게는 수업 기록·리포트 조회 API를 제공하지 않음 — 원장·선생의 내부 산출물임
- 선생은 담당 학생의 수업 기록·리포트를 읽을 수 있으나 수정·삭제는 본인 작성분만 가능함
- 원장은 수업 기록·리포트 전체를 수정·삭제할 수 있음
- 리포트 API는 학생별 최근 리포트 작성일을 제공하지 않음
