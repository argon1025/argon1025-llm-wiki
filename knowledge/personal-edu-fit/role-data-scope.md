# 역할별 데이터 범위

## 적용 대상

- 권한을 강제하는 edu-fit-backend, 화면에 표시할 값을 조회하는 edu-fit-frontend

## 규칙

- 선생 담당 학생(담당 학생)은 삭제되지 않은 수업 설정의 담당 선생이거나 탐구 업무의 현재·이전 담당자(배정 이력 포함)인 학생이며, 학생 단위 선생 API 전부에 같은 정의를 씀
- 학생은 본인 데이터만 조회하며, 모든 권한·소유권 검증은 서버(edu-fit-backend)가 강제함
- 원장 학생 상세 API는 수업 담당 선생·탐구 담당자를 싣지 않으므로 edu-fit-frontend가 수업 설정 목록·업무 목록의 학생 필터 조회로 표시함 — member 도메인이 course·consulting에 의존하는 것을 피함
