# 위키 PR 본문

## 적용 대상

- update·add 스킬이 같이 쓰고 게시하는 위키 PR 본문

## 규칙

- 위키 PR `사실 목록` 표의 액션 칸은 사실이 거친 판정을 장 순서대로 ` → `로 잇고 우선순위로 하나를 고르지 않음 — 사실 하나가 불릿 여러 개로 반영돼 검토가 일부만 지웠는지 가를 수 없고, 하나만 고르면 부분 삭제 사실의 반영과 재배정 사실의 원 문서 교체가 가려짐

## 함정

- update의 재배정 반영(apply.md 4장)이 같은 실행에서 다른 사실이 만든 불릿을 교체하면, 위키 PR 사실 표에서 원래 사실 행은 `추가`로 남고 그 불릿을 바꾼 재배정 사실 행만 `수정`으로 보임
