# 계획 스킬 설계

## 규칙

- 기존 코드 재편·삭제는 에이전트가 자율 수행하지 않고 지울 범위와 함께 후보로만 올림 — 범위 밖 리팩터링 억제, 외부 계약 파손과 리뷰 diff 증가를 피하고 결정권을 사용자에게 두기 위함
- 5절 독립 라운드의 미룸 기준은 다른 답에 따라 필요 여부나 선택지가 바뀌는 질문임 — 문구가 바뀌는 질문을 기준으로 삼으면 문구는 같고 앞 답에 따라 필요성만 사라지는 질문이 걸러지지 않음

## 결정

- 기존 코드 유지 편향은 3절 구조 축(무엇을 물을지)과 4절 기존 코드 판정(무엇이 최소인지)으로 나눠 다룸 — 3절 하나로 합치면 4절 사다리가 새 코드 단위에만 적용되어 ② 코드베이스에 이미 있음을 통한 기존 코드 재사용이 그대로 통과함
- plan.md 형식에 결과 구조 절을 신설하지 않음 — 구조는 질문 단계의 AskUserQuestion preview로 승인 전에 확인시켜 plan-format 절 증가를 피함
